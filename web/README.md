# 电路实验室 · 电路与 MCU 学习原型

当前可玩的是第 1 关「分流节点」，对齐大学电路分析入门。搭建区预设固定的 9 V 直流电源、节点 A 和 GND；玩家放置三只可独立选值的电阻，搭建一条串联支路与两条并联支路，测量节点电压、总电流、支路电流和元件功率。课程路线见 [课程与关卡蓝图](../课程与关卡蓝图.md)。

## 运行

```bash
npm install
npm run dev
```

默认进入第 1 关。关卡数据和模型扩展方式见 [LEVEL_ARCHITECTURE.md](LEVEL_ARCHITECTURE.md)。

## 交互与题设

- R1、R2、R3 默认均为 1 kΩ，可直接从元件库拖入画布；放置后点击电阻可以调整阻值。元件吸附孔点网格，按住一个端点拖到另一个端点松开即可连线。
- 参考拓扑是电源 → R1 → 预设节点 A，再由 R2、R3 分别接地。节点 A 是画布上可接线、可测量的固定测点；与它用导线连通的端点属于同一节点。一个参考解为 R1 = 1 kΩ、R2 = R3 = 2 kΩ：节点 A 约 4.5 V，总电流约 4.5 mA，两支路各约 2.25 mA。游戏按实际接线和电气指标判题，允许等效的合格接法；等效电阻、压降及 KCL/KVL 仍可结合探针读数探索，无须填写数值。
- 拖入探针并接触端点或导线，查看相对 GND 的节点电压和对应支路电流估算。接线和阻值变化后，测量、元件状态、电流动画与目标检查实时更新。检查电路可查看原因或通关结果；撤销、删除和重置仍可使用。
- 短路时停止求解，悬空节点不会显示为测得的 0 V。模型会区分断开的支路、目标数值不符和电阻功率超限。

## 模型边界

第 1 关使用理想导线与理想直流电源的电阻网络节点求解，不是通用 SPICE。电流是由欧姆定律和 KCL 得到的支路估算，不是单支电压探针直接测得的电流；理想导线环路中的电流分配没有唯一值。电阻功率按 `P = I²R` 计算，额定值为本关题设参数。

早期 GPIO—电阻—LED 教学模型仍保留在代码中供后续章节复用，但不再是当前第 1 关，也不代表 MCU 固件仿真。
