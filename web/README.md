# 电路实验室 · MCU 电路学习原型

原第 32 关已成为第 1 关「点亮信号灯」。此前拆出的第 2–5 关现已合并到这一关：玩家在同一块空白画布上选阻值、搭接电路、翻转 LED、移动探针，直接观察电流、电压与波形。页面参考 `../assets/ui-concept-game-dark.png`。

## 运行

```bash
npm install
npm run dev
```

默认进入第 1 关。关卡数据及后续扩展方式见 [LEVEL_ARCHITECTURE.md](LEVEL_ARCHITECTURE.md)。

## 交互

- 点击元件库卡片打开参数说明；限流电阻在此选择阻值。点击本身不把元件放入画布。选好后把元件拖进搭建区，位置吸附孔点网格。探针也通过拖入放置；导线使用画布上的连线按钮和端点点击。
- 点击画布上的元件，会在它下方打开操作选单。电阻可随时换值，LED 可翻转；元件和导线可删除。拖动元件后选单跟随，撤销和重置仍可使用。
- 接线、阻值、方向或探针位置变化后，任务目标、LED 状态、电流动画、电压和波形立即更新。电流方向使用沿导电支路移动的短线，不以通关为前提。
- 第 1 关给出 47、100、220、330、470、680 和 1000 Ω 候选值。电阻选单只解释 `I = U ÷ R` 的计算方法与已知量，不给各选项的预计算结果。47 Ω 在本关简化模型中超过 20 mA 比较线，能用于观察未达标反馈；这条线不是所有 MCU 或 LED 的通用安全值。
- 「检查电路」在符合目标时显示通关弹窗；缺件、断路、LED 反接、GPIO/电源短路、绕过电阻直驱 LED，或电流超出本关目标时显示原因与重试入口。直驱 LED 的失效动画是教学演示，并不声称真实 LED 一定烧毁。
- 右侧的自由实验建议引导玩家换阻值、翻转 LED 和比较测点；这些探索不拆成重复关卡，也不影响基础电路的通关判定。

## 模型边界

当前使用可复用的 GPIO → 电阻 → LED 教学模型，并非通用 SPICE 或 MCU 固件仿真。LED 正向压降按本关约 2.0 V、GPIO 高电平按约 3.3 V 计算。探针电压是相对 GND 的节点估算；电流是模型识别的支路估算，不是单支电压探针实际直接测得的电流。悬空或故障节点不会冒充 0 V。

真实 GPIO 驱动能力和 LED 参数应以器件数据手册为准。可参考 [ST GPIO 应用笔记 AN4899](https://www.st.com/resource/en/application_note/dm00315319-stm32-gpio-configuration-for-hardware-settings-and-lowpower-consumption-stmicroelectronics.pdf) 与 [Vishay LED 产品目录](https://www.vishay.com/en/leds/green/)。
