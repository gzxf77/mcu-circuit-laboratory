# 电路实验室 · 电路与 MCU 学习原型

当前可玩第 1 关「参考方向与功率」、第 2 关「源与受控源」与第 3 关「功率预算与供电设计」（第 1 章重建版三关），对齐大学电路分析入门与邱关源《电路》第 6 版第 1 章；三关的答题步骤互不雷同：搭建+判断 / 搭建+整定 / 搭建+选器件档位。第 1 关：搭建区预设固定的 12 V 电源、6 mA 电流源、节点 A 和 GND；玩家放置两只可独立选值的电阻，让节点 A 稳定在约 3.0 V——这要求把电流源接成「从节点 A 抽走 6 mA」的方向——再逐只元件判断它此刻在吸收还是释放功率。参考解 R1 = R2 = 1 kΩ：节点 A = 3.0 V，电源释放 108 mW、R1 吸收 81 mW、R2 吸收 9 mW、电流源吸收 18 mW（被外电路充电），功率守恒。这一关的新知识点是参考方向、功率的符号与吸收/释放，不再重复高中已覆盖的欧姆定律与串并联。第 2 关换成受控源与两级分压：9 V 电源经 R1 到节点 A，节点 A 再经 R2 到节点 B、经 R3 回 GND；另有一只压控电流源按 I = g·U_B 注入节点 A，**g 由玩家在元件菜单里用滑块整定**（默认 0.25 mS）。玩家要把节点 B 调到约 3.6 V、受控源输出调到约 1.8 mA（参考解三只电阻都是 1 kΩ、g = 0.5 mS：U_A = 7.2 V、U_B = 3.6 V、I = 1.8 mA）。g 与阻值缺一不可：默认阻值配 0.5 mS 落在 4.70 V，参考阻值配默认 0.25 mS 落在 3.27 V。受控源的输出始终等于 g·U_B，控制电压为 0 就没有输出——它不能独立激励电路。第 3 关换成「自由搭建 + 选器件档位」：12 V 电源要给一只固定的 100 Ω 负载供电，要求负载约 3.0 V、约 90 mW。串联部分由玩家自己拖电阻、接线、选阻值，而且**每只电阻还能选额定功率档位（¼ W 或 ½ W）**，板上标签会写明 `R1 · 600 Ω · 250 mW`。串联部分要吃掉 9 V、通过 30 mA，等效阻值必须是 300 Ω：一只 300 Ω 独自扛 30 mA 就是 270 mW，¼ W 器件超限——要么把它的额定功率换成 ½ W，要么用两只 600 Ω 并联让电流各半（每只 135 mW）。课程路线见 [课程与关卡蓝图](../课程与关卡蓝图.md)。

## 运行

```bash
npm install
npm run dev
```

默认进入第 1 关。关卡数据和模型扩展方式见 [LEVEL_ARCHITECTURE.md](LEVEL_ARCHITECTURE.md)。

## 交互与题设

- 第 1 关的 R1、R2 默认 1.5 kΩ（要改到 1 kΩ），第 2 关的 R1、R2、R3 默认 1.5 k/1 k/1.5 k（参考解是三只 1 kΩ，跨导还要从 0.25 mS 调到 0.5 mS）；第 3 关的负载固定 100 Ω，拖入的电阻默认 1 kΩ（不是答案的 300 Ω）；放置后点击电阻可以调整阻值和额定功率档位。元件吸附孔点网格，按住一个端点拖到另一个端点松开即可连线。
- 第 1 关的参考拓扑是 12 V 电源 → R1 → 节点 A → R2 → GND，6 mA 电流源接在节点 A 与 GND 之间、方向由玩家决定。节点 A 是画布上可接线、可测量的固定测点；与它用导线连通的端点属于同一节点。电流源接成「流入端接节点 A、流出端接 GND」时它在从节点 A 抽走 6 mA：节点 A = 3.0 V，各元件功率为 −108 / +81 / +9 / +18 mW（吸收为正）。接成相反方向时它向节点 A 注入 6 mA，节点 A 变成 9.0 V，这一关就不达标——同一只电流源，方向不同，功率的正负也相反。
- 第 3 关只预置 12 V 电源、节点 A、GND 和固定的 100 Ω 负载（参数菜单里它叫「负载 R2」，阻值不可改）。四个候选方案各自给定串联器件的阻值与接线：方案 A 一只 300 Ω、方案 B 一只 470 Ω、方案 C 一只 100 Ω、方案 D 两只 600 Ω 并联。判定仍只看节点 A 电压与负载功率两条读数，器件过载由实时反馈拦下：方案 A 的读数与正解相同（3.0 V / 90 mW），但 R1 耗散 270 mW 超过 250 mW 额定值，会被判为「方案读数可能对，但器件已经超过额定值」，并给出并联分摊的解释。
- 第 2 关的参考拓扑是 9 V 电源 → R1 → 节点 A → R2 → 节点 B → R3 → GND，压控电流源的流出端接节点 A、流回端接 GND，控制量取节点 B 对 GND 的电压（板上画出「节点 B」符号，探针也可测）。节点 B 没有别的支路，所以 U_A = 2U_B（R2 = R3 时）；把它代进节点 A 的 KCL 得到 9 = (3 − gR)U_B。参考解三只电阻都是 1 kΩ、g = 0.5 mS：U_A = 7.2 V、U_B = 3.6 V、I = 1.8 mA。用 2 kΩ ∥ 2 kΩ 当 R1 同样合格；把 g 调到别的值或让三只电阻不等，两项读数都不会同时达标。
- 游戏按实际接线和电气指标判题，允许等效的合格接法；等效电阻、压降及 KCL/KVL 仍可结合探针读数探索，无须填写数值。
- 搭建区底部的「查看答案」会打开本关的参考解：参考接法、参考取值、参考读数、各元件功率与功率判断答案。这些内容由关卡数据解算得出，任何满足目标读数的等效接法同样合格。
- 拖入探针后拖动它的手柄去接触端点或导线，查看相对 GND 的节点电压和对应支路电流估算（画布上没有连线/测量模式切换：点击端点始终是连线，测量只靠拖探针）。接线和阻值变化后，测量、元件状态、电流动画与目标检查实时更新。检查电路可查看原因或通关结果；撤销、删除和重置仍可使用。
- 电源短路、电流源两端短接时停止求解；悬空节点不会显示为测得的 0 V，电流源回路未闭合时也不会把额定电流硬推进网络。模型会区分断开的支路、目标数值不符和电阻功率超限。学生误接造成的开路、短路只是实时反馈，不再是关卡目标——故障注入题型已从关卡目录移除。

## 模型边界

三关都使用理想导线与理想源的电阻网络节点求解，不是通用 SPICE：第 1 关有电压源与理想电流源，第 2 关是电压源加压控电流源（输出 g·U控制 由节点电压决定，g 可由玩家整定，第一版只做压控型），第 3 关是电压源加纯电阻网络——独立源被给定的那个量恒定、另一个量由外电路决定，受控源则连"另一个量"都由电路里的控制量决定。第 1 关按参考方向报告每个元件**带符号的功率**（吸收为正，ΣP吸收 = ΣP释放），判题的目标之一就是玩家对吸收/释放的判断。电流是由欧姆定律和 KCL 得到的支路估算，不是单支电压探针直接测得的电流；理想导线环路中的电流分配没有唯一值。电阻功率按 `P = I²R` 计算，额定值为本关题设参数。

早期 GPIO—电阻—LED 教学模型仍保留在代码中供后续章节复用，但不再是当前课程关卡，也不代表 MCU 固件仿真。
